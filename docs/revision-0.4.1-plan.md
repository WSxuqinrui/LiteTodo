# 0.4.1 修正范围

依据用户最新截图，继续在现有原生界面中完成以下修改。

1. 浮球隐藏再显示会重新创建 Windows 窗口，但 FLTK 保留旧形状缓存。窗口重新创建时重设圆形遮罩；回归覆盖浮球开关、主窗口隐藏、重绘、移动和缩放。
2. 主页面卡片中的子任务进度可展开为清单，直接勾选并立即保存。保持父任务显式完成规则；取消勾选已完成父任务的子项时恢复父任务。编辑草稿存在时先回到草稿，避免覆盖。
3. 多行输入框使用单独的内边距，让光标与文字离开圆角边缘。编辑及设置滚动区域统一使用细圆角滚动条，保留滚轮、拖动和点击轨道功能。
4. 用隔离数据验证实际操作、控件渲染和窗口形状，重新构建便携 ZIP，核对完整目录仍小于 5,000,000 字节。

沿用本地 SQLite、原创矢量图标及原有依赖，不引入图片或界面框架。Windows 本机验证与 macOS/Linux、混合显示器 DPI 验证分别报告。
