# LiteTodo 0.4.2 修复验证

验证日期：2026-10-12。基线：`ee95ba8`。数据和窗口检查使用独立目录及本测试启动的进程，没有打开或更改用户任务库。

## 修复范围

| 原问题 | 修复与证据 |
| --- | --- |
| 删除后编号复用、旧草稿覆盖新任务 | 持久化编号水位；编号删除、重启及导入后不回退；保存事务检查修改令牌 |
| 另一连接完成或修改任务后被旧草稿撤销 | 任务及关联修改触发令牌更新；保存拒绝冲突并保留草稿 |
| 子任务拖动误删其他项 | 按下、释放须为同项同动作，移动或离开取消手势；正常点击继续有效 |
| 主窗口恢复丢失透明度 | 每次显示重新应用设置；原生 HWND 重建后 80% 对应 alpha 204 |
| 浮球恢复丢失置顶 | 每次显示重新应用置顶；检查原生 WS_EX_TOPMOST |
| 浮球文件拖放污染已有草稿 | 草稿存在时拒绝拖放后续步骤，不向旧草稿追加附件 |
| 迁移失败后残留数据库阻止重试 | 关闭候选连接后清理本次候选文件；已有目标文件保留 |
| 系统日期回拨删除当天备份 | 最多保留七份快照，并保留本次成功创建的当天快照 |
| 浮球悬停恢复时离开编辑页 | 显示现有页面，保留编辑上下文 |
| 删除末项产生滚动空白 | 子任务、附件删除及布局变化后重新限制滚动偏移 |

独立审查额外发现并修复：延后提醒重新授权旧草稿、删除确认未校验修改版本、旧通知回执误确认复用编号的新任务、发布包遗漏版本记录链接。
