# Pometodo 交互对照 · 0.4.1

以用户提供的截图为主要交互依据，参考此前查阅的公开源码版本。独立实现代码及图标，不复用品牌或图片资源。

| 参考 | 本版 |
| --- | --- |
| 页内新增及快捷日期 | 任务/日期/提醒/确认页内导航，五项交付快捷按钮 |
| 首界面播放与更多菜单 | 常显开始/暂停按钮；页内菜单完成、加急、搁置、删除，删除可取消 |
| 搁置 | 独立状态筛选，暂停提醒，开始/完成结束搁置，保留子任务及附件 |
| Logo 切换控制台 | 快捷面板、状态看板、完整列表，窄窗口自动单列 |
| 图钉及设置 | 带文字、悬停与填色选中反馈 |
| 主题、颜色、透明度 | 系统/浅/深主题、五种配色、45%—100%透明度 |
| 浮球设置 | 默认小团子，空闲开心、8项起疲惫、加急/逾期冒火；圆形窗口无方框，自由/贴边停留展开并保留编辑页 |
| 提醒异常 | Windows 检查通知开关、等待显示回执，未显示转应用内提醒；确认/延后及系统设置入口 |
| 智能整理 | 用户确认先采用本地按行整理、日期与加急识别、预览后事务保存；云与微信未接入 |
| 备份 | 每日最近7份、立即备份、导出/校验导入、导入前保护 |
| 目录管理 | 打开目录、复制切换数据库目录、设置新附件位置；旧数据保留 |
| 子任务及附件 | 主页面展开清单直接完成/恢复子项，立即保存；父子约束，编辑保存/取消隔离，附件复制草稿 |
| 小窗口裁切 | 最小440×620，设置和长编辑页使用细圆角滑块，中文换行，输入光标使用统一内边距 |
| 贴在桌面 | 暂不可用，等待完善桌面重启时恢复 |

浮球是唯一独立窗口，业务页不创建弹窗。Windows自动启动与全局快捷键已接入，macOS/Linux尚未适配这两项；三平台的实际分发仍需各自验收。
