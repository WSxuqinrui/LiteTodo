# 0.4.1 界面与本地功能改版

0.4.1 修正浮球隐藏再显示后的方框：FLTK 销毁 HWND 时仍缓存旧窗口的形状尺寸，重建同尺寸窗口会跳过区域提交。Ball 的虚拟 show 在创建窗口前重新设置遮罩，覆盖主窗口隐藏时框架自动重建非模态浮球的路径。原生区域回归涵盖连续三轮浮球和主窗口开合、移动/重绘、应用内 150% 缩放及恢复；按物理窗口尺寸检查四角及中心。

卡片子任务进度可展开为勾选清单，子项名称按 UTF-8 字符边界最多两行；统一生成绘制和点击的布局。勾选仅更新该子项并立即刷新进度，不自动完成父任务；取消已完成父任务的子项会恢复父任务。子任务数据只在展开后查询，刷新时只读取已展开且可见的父任务。编辑草稿存在时先返回草稿，避免后续保存覆盖快捷修改。

多行输入单独设置左右14、上下12的框内边距，文本绘制、光标、选区与鼠标定位使用同一框尺寸。编辑及设置使用 SoftScroll：保留 FLTK 内容布局和滚轮，自绘圆角滑块覆盖传统箭头/凹槽，12像素命中区，按实际滑块长度和滚动范围映射拖动/轨道点击。共用胶囊绘制支持纵向，避免竖滑块变成细线和圆点。

本轮增加卡片常显开始/暂停和更多菜单，完成、加急、搁置、删除都直接可达。菜单在同一 TaskBoard 内绘制，位置根据可见区域向上/下调整；点击外部、滚动、失焦或换页关闭。删除用当前主窗口确认，不创建业务弹窗。

数据库 v5 原子新增搁置状态，升级前保留快照。搁置清除进行中，暂停提醒；开始/完成解除搁置，编辑不意外恢复。异步通知确认也检查当前未完成、未搁置和时间匹配。

浮球白框的原因是自定义 draw 跳过基类窗口绘制，平台形状未提交；现在先执行基类，再绘制四倍采样的小团子。Windows 自身窗口区域回归检查确认四角不属于窗口、中心属于窗口。表情顺序为加急/逾期、8项以上疲惫、空闲开心、进行中认真、普通微笑；避免持续动画消耗空闲 CPU。悬停去掉必须贴边的条件，增加停留延时并在离开/拖动时取消。

Windows 旧版只按 Shell_NotifyIcon 返回成功标记已提醒，系统实际拒绝显示时会丢提醒。现在检查 Windows 通知总开关和 SHQueryUserNotificationState，等待 NIN_BALLOONSHOW；最多10秒无显示回执则取消并转页内提醒。一次只保留一个系统请求，其他提醒立即兜底；NIIF 实时请求避免系统长时间排队。显示失败不消费数据库提醒，用户确认或延后才更新。后台确认通过弱引用投递主线程，导入时替换队列隔离旧请求。

应用内提醒作为第八个业务页，未保存草稿或确认页保持原位置，顶部提醒入口持续可见。多个提醒逐个确认；已删除、完成、搁置或改期的旧提醒从待处理列表去掉。macOS/Linux 仍只能确认服务接受通知，并在文字中明确这一边界。

复核修正三处边界：到期查询在 LIMIT20 之前参数化排除已经排队的任务，后续任务不会被前20条未确认提醒挡住；延后当前正在编辑的任务时同步草稿提醒时间，保存不会覆盖延后；Windows 已显示通知等待终止回执，未显示超时/Explorer重启时更换托盘身份并过滤旧身份，避免旧点击确认新请求。

参考接口：[Shell_NotifyIcon](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)、[SHQueryUserNotificationState](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shqueryusernotificationstate)。

依据用户提供的任务、外观、浮球、智能整理、备份截图。保持单主窗口导航、跨平台核心与解压发布目录小于 5,000,000 字节。

设置固定高度造成小窗口裁切，现改为独立滚动区域；标题、说明、按钮逐行排布，中文按字符边界换行。图钉及设置按钮使用文字、悬停反馈和持续填色的选中状态。主界面任务标题 17 号粗体，最多三行；紧凑卡片仍保留动作区。

主题使用颜色角色而非硬编码背景，支持五种强调色和浅/深主题。开关以矢量胶囊和圆形绘制；透明度滑条使用简洁轨道。图标沿用原创 SVG/ICO/ICNS 和矢量按钮，未新增图片框架。

浮球仍是唯一独立桌面窗口。配置数量/表情、线框、颜色、贴边、双击与拖文件；经过展开复用主窗口，不开列表弹窗。本地提示为固定短句，不模拟云聊天。

本地文本整理按行解析，识别相对日期与加急。预览只读，输入改变后失效；保存前再次校验文本快照，批量任务一次事务提交。Windows 热键冲突时保留旧注册，录制失败回滚设置。云与微信接口留待后续设计。

附件先留在编辑草稿，保存时复制到独占目录，再与任务/子任务同事务写入引用；失败清理本次复制文件，取消不碰原件。每任务最多40个附件、单文件50MB。删除引用不自动删除附件实体。

此前 v4 增加附件表，v5 再增加搁置字段。导入先验证原版本身份、完整业务列、SQLite完整性及任务关联，副本升级后生成导入前备份，再使用 SQLite Backup API 原子替换；恢复同时更换异步通知队列，旧确认不会写入恢复库。数据迁移先复制、保存启动位置后交换连接，原库保留。

自动备份只修剪精确受控命名的最近7份快照，不删除手工或未知文件。备份只含数据库，附件换机需另行复制。用户可编辑的目录输入不会提前影响自动启动。

贴桌面尚未开放：直接把业务窗口挂到 Explorer 会影响窗口生命周期；需独立设计恢复后再启用。Windows编译、存储及控件渲染检查与真实鼠标/输入法/混合DPI、多平台验收分开报告。
