# 轻待办：5 MB 体积验证原型

这是用于判断技术路线的实验原型，不是完整产品或正式发布版本。

## 已确认目标

- Windows、macOS、Linux 桌面平台，共用 C++17 + FLTK + SQLite 核心。
- 单个平台、单架构、解压后程序和随包运行依赖合计不超过 5,000,000 字节。
- 不计用户任务数据库和附件；禁止通过漏算必需 DLL 来达到指标。
- 本次范围：中文任务输入、新增/编辑/完成/删除/搜索、本地保存、托盘、浮球与三项预览、系统通知、简单定时提醒。
- 用户进一步确认参考 Pometodo 的界面和快捷按钮：采用紧凑单列、横向状态分类、卡片就地操作，保留 5 MB 目标。
- 默认无样例数据、免账户、无启动网络请求，实验模式数据单独隔离。

## 实施顺序

1. 固定 FLTK/SQLite 版本及下载校验值，独立目录构建。
2. 为任务存储编写真实 SQLite 测试，验证中文、特殊字符、持久化、状态和删除。
3. 实现共享界面和平台适配；系统能力不可用时保留主窗口，清楚提示。
4. Windows Release 静态链接编译器运行库，检查实际 PE 导入和随包体积。
5. 在独立数据目录运行自动检查，观察真实窗口并记录资源占用。
6. 提供 macOS/Linux 构建入口和自动构建配置；没有相应主机时标为未核验。

## 验证边界

- 系统通知接口提交成功不能证明用户看到了通知。
- 自动注入中文字符串不能证明所有中文输入法的组合输入都兼容。
- Linux 首轮选择 X11 后端，可通过 XWayland运行；托盘依赖桌面是否提供 XEmbed 托盘宿主。
- macOS 分别构建 arm64 / x86_64；未签名、公证的实验包不声称满足正式分发体验。
- 不能将 Windows 体积或功能测试外推到另两个系统。
